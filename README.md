# devrimcaner.com

Static portfolio source and GitHub Pages artifact for [devrimcaner.com](https://devrimcaner.com).

The Next.js project is in [`devrimcaner/`](./devrimcaner); its setup, checks, content model, and deployment instructions are documented in [the project README](./devrimcaner/README.md). The top-level `docs/` directory contains the generated static site used by the existing GitHub Pages deployment.
